Assignment 1: Playwright Library provides unified APIs for launching and interacting with browsers, while Playwright Test provides all this plus a fully managed end-to-end Test Runner and experience.

Assignment 2: When we use the page fixture within our test, we directly invoke the page that the browser context is pointing to. Whereas when we use the browser fixture and create a page for the browser context we create an isolated page and browser context. This is useful when we want to work with window handling. The main tab will be accessed using the page fixture whereas the child tab will be accessed by creating an isolated browser context and then assigning to the child tab to the page of this isolated browser context.
